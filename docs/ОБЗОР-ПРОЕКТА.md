## 1. Назначение

**TuneDraft** — Android-приложение «табулатурная тетрадь для бас-гитариста»:

- 4 струны **E–A–D–G** (№2; модель хранит струны как список MIDI-нот — задел на 5-ю струну),
  лады **0–24** (№3);
- документ — «лента строк»: **таб-строки** (сетка ячеек «струна × колонка», колонки с
  нотами-цифрами и тактовыми чертами) и **текст-строки** (№6);
- ввод — тап → контекстные меню ячейки/колонки в нижней панели (№5, №21, №35);
- хранение — JSON-файлы `tet-<id>.json` + карман автосохранения (№26, №29);
- экспорт — **только PDF**, листы **A4 портрет** (№7, №8);
- воспроизведение/синтез звука в MVP **не входит** (№9); интерфейс — **русский** (№31).

Ключевой архитектурный принцип (№14): **модель и layout отделены от рендера** — один
layout-движок (чистый JS: данные → координаты) кормит два рендерера (Skia для экрана,
HTML→PDF для экспорта), поэтому экран и PDF всегда согласованы.

## 4. Спек-система `docs/specs/`

Спеки — **источник истины до кода** (ADR-0001: bootstrap спек-системы раньше кода;
ADR-0002: расположение `docs/specs/`). Форматы, протокол обновления и правило
`<!-- TODO: verify -->` (маркер — всегда заявление о ещё не написанном коде) определяет
[META.md](specs/META.md); навигация «задача → спека» — [INDEX.md](specs/INDEX.md);
рабочие процессы — WORKFLOW.md. Число решений `(№NN)` отсылает к таблице в
[КАРТА-ПРОЕКТА.md](КАРТА-ПРОЕКТА.md).

Состав: **6 доменов** — `app-shell` (навигация, режимы чтения/правки, тулбар, Back, i18n,
тема), `layout-engine` (геометрия и переносы), `tabulature` (модель тетради: README +
notebook-model), `editing` (README + cell-and-column-menus + lines-and-gestures),
`storage` (README + pocket + library), `rendering` (README + pdf-export) — итого 12
доменных файлов; плюс `architecture/` (layers.md — слои, data-flow.md — пятистадийный
конвейер операции, пока forward-looking), `contracts/_template.md` (реальных контрактов
нет) и `decisions/` (ADR-0001, ADR-0002, ADR-0003 + шаблон). INDEX.md соответствует
фактическому набору файлов.

Планирующие документы рядом: [КАРТА-ПРОЕКТА.md](КАРТА-ПРОЕКТА.md) — все продуктовые
решения №1–№40, дорожная карта 0–10 и список отложенного (§4);
[ПЛАН-ФОРМАЛИЗАЦИИ.md](ПЛАН-ФОРМАЛИЗАЦИИ.md) (2026-09-17) — уже выполненный план
развёртывания КАРТЫ в спек-систему.

## 5. Дорожная карта: текущий этап

Этапы 0–10 (КАРТА §3; критерии приёмки у каждого этапа):

| Этап | Содержание | Статус |
| --- | --- | --- |
| 0 | Инструменты (Node, Android SDK, проверка Android) | ✓ закрыт: эмулятор AVD TuneDraft_Tablet (Android 15 / API 35); USB-проверка планшета Iconia X12 отложена до первого подключения |
| 1 | Каркас Expo (TS) + скелет слоёв `src/` | ✓ закрыт («scaffold landed», INDEX.md/META.md) |
| **2** | **Модель данных + фикстуры + юнит-тесты (№34)** | **← следующий** |
| 3–8 | layout-движок → Skia-рендер → ввод → лента строк → сохранение/библиотека → PDF-экспорт | не начаты |
| 9–10 | локальный `.apk` → README + пуш на GitHub | не начаты |

То есть репозиторий находится **между этапами 1 и 2**: весь каркас и гавернанс готовы,
доменного кода нет, ближайшая работа — модель тетради (`version`, строки, колонки с `id`,
ноты/черты, тексты ≤ 3 на колонку) по `domains/tabulature/`.
