## 4. Что остаётся за пользователем

По честному хвосту README прогона 26.10 (плюс актуализация на сегодня):

1. **Полная визуальная приёмка канвы** — Skia не читается дампами: цифры лада, красные черты,
   тексты под колонками — по скриншотам (глазами пользователя).
2. **UI-цикл «+» → Таб-строка / «+» → Текст-строка и полный лонг-тап-цикл текст-строки** —
   в прогоне 26.10 модалка открывалась и отменялась, полный цикл вставки строк в UI не
   завершён; семантика полностью покрыта юнит-тестами контроллера (insert-tab-line /
   insert-text-line / systemCapacity / position-out-of-range).
3. **Живые undo/redo в режиме чтения в UI** — гейтинг подтверждён кодом и юнит-тестами;
   в чтении UI-проверено отсутствие панелей и «+», сами undo/redo в чтении тапами не
   прогонялись.
4. **Повтор смоук-теста на текущем дереве** (по желанию): `npm run android` (один раз,
   сборка+установка) → `npm run dev:android` (эмулятор + Metro + приложение). Нативная часть
   не менялась с 25.10, JS не менялся с 26.10 — ожидается идентичное поведение.

Известные замечания среды прогона 26.10 (не дефекты приложения): LogBox-тост перехватывает
тапы до dismiss; таскбар Android 15 перекрывал нижние ~100px (SystemUI/launcher3 временно
отключались и включены обратно); зона статус-бара не принимает `input tap`; часть поздних
тапов терялась (компенсировалось повторами с проверкой состояния).
