## Верификация тапов
Достоверение состояния после каждого шага — uiautomator dump (панель режимов: «Тактовая черта»
= вставка, «Удалить ноту» = правка/нота есть, «+» = нет выделения; наличие меню/модалок/предупреждений).
Геометрия зон тапа — дамп hitZones плана (demoNotebookFixture, advance 9.6094, width 1280dp) прогоном jest.

## Замечания среды (НЕ дефекты приложения)
1. LogBox-тост «Open debugger to view warnings.» перехватывает тачи основного окна RN, пока не dismissed
   (после тапа по нему исчезает). Из-за этого первые тапы по кнопкам не срабатывали.
2. Таскбар Android 15 (launcher3) перекрывал нижние ~100px: кнопки нижних панелей (y>1500) были
   недостижимы; на время сценария SystemUI и launcher3 отключались (pm disable-user) и
   ВКЛЮЧЕНЫ ОБРАТНО по завершении.
3. Зона статус-бара (верхние ~60px) не принимает `input tap` — тулбар нажимался по y=64.
4. Часть поздних нажатий `input tap` терялась (квантование событий эмулятора) — компенсировалось
   повторами с проверкой состояния.

## Что осталось за пользователем (не покрыто UI-прогоном)
- Полная визуальная приёмка канвы (Skia не читается дампами): цифры лада, красные черты, тексты
  под колонками — по скриншотам.
- Цепочки «+» → Таб-строка / «+» → Текст-строка и лонг-тап-вставка текст-строки: модалка лонг-тапа
  открывалась и отменялась (наблюдалось), полный цикл вставки строк в UI не завершён — семантика
  покрыта юнит-тестами контроллера (insert-tab-line/insert-text-line/systemCapacity/position-out-of-range).
- Живые undo/redo в режиме чтения: гейтинг подтверждён кодом контроллера (history-интенты разрешены
  в чтении) и юнит-тестами; в UI проверено, что в чтении панели и «+» недоступны.
