# i18n — словарь строк интерфейса

Все видимые пользователю строки приложения всегда приходят из словаря
(решение №31 КАРТЫ-ПРОЕКТА): русский — базовый язык, английский —
добавляемая опция. Компоненты получают строки только через `t(key)`.

## Состав

- `ru.ts` — базовый словарь (объект `ru`, тип `TranslationKey` = union его ключей).
- `index.ts` — функция `t(key: TranslationKey): string`.

## Правила

- Компонент содержит только ключи строк, но не их значения; появление
  литеральной русской строки в компоненте — дефект.
- Новый ключ добавляется в `ru.ts`; опечатка в ключе ломает сборку —
  это гарантия `TranslationKey`.
- Добавление языка = новый словарь той же формы + переключение в `index.ts`;
  компоненты не меняются (точка расширения app-shell, №31).

## Связь со слоями

i18n — часть Entry Points (app-shell владеет языком интерфейса, см.
[app-shell.md](../../docs/specs/domains/app-shell.md)); `src/i18n` не зависит
от других слоёв `src/` и доступен всем слоям как чистая утилита без I/O.
