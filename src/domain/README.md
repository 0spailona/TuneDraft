# Domain — предметное ядро

Чистый слой TuneDraft: правила и данные без окружения. Домены, которые
здесь живут (по [layers.md](../../docs/specs/architecture/layers.md), Domain Mapping):
табулатурная модель (`docs/specs/domains/tabulature/`) и геометрия
layout-движка (`docs/specs/domains/layout-engine.md`).

## Правила слоя

- Импортирует только стандартную библиотеку TypeScript и чистые утилиты (R1).
- Всегда свободен от I/O, фреймворков и инфраструктурных импортов:
  нет `react-native`, `expo-*`, файловой системы, сети, часов (R1).
- Компилируется и тестируется изолированно, без эмулятора (инвариант layers.md).
- Внешние возможности получает только через интерфейсы, объявленные
  на стороне потребителя (инверсия зависимостей, R3) — сам их не объявляет
  реализациями.

## Что сюда кладём

Чистые типы и функции: сущности тетради (строки, колонки, ноты, черты,
тексты, строй), каскады мутаций, `(model, width) → coordinates` layout-движка.

## Чего здесь не будет

React-компоненты, хранилища, рендереры, работа с файлами — всё это слои
ниже (Infrastructure) или выше (Application, Entry Points).
