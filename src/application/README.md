# Application — сценарии использования

Слой оркестрации TuneDraft: превращает проверенное намерение пользователя
в мутации модели. Домен по [layers.md](../../docs/specs/architecture/layers.md):
editing — координация мутаций и история undo/redo ≤ 3 шагов (№25).

## Правила слоя

- Импортирует Domain напрямую (R2).
- Возможности Infrastructure получает только через интерфейсы,
  которые определяет сам (dependency inversion, R2–R3); сам Infrastructure
  напрямую не импортирует.
- Не знает про экраны, жесты и навигацию — это Entry Points.

## Что сюда кладём

Use cases: применение операций ячейки/колонки, вставка и перемещение
строк ленты, история отмены (№25), транзакционные границы мутаций.

## Чего здесь не будет

React-компоненты и обработчики жестов (Entry Points), JSON-файлы
и AsyncStorage (Infrastructure), сами правила модели (Domain).
